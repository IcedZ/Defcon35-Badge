# Prototype board: Guition JC4827W543

The prototype display board is a **Guition JC4827W543** (4.3", 480×272). It was
sold as an "ESP32-4827S043" and shipped with that board's documentation, but the
two boards are **not** compatible — the 4827S043 docs, pin map, and vendor
demos do not apply here.

| | JC4827W543 (this board) | ESP32-4827S043 (seller's docs — ignore) |
|---|---|---|
| Display controller | NV3041A, **QSPI** | ILI6485 / ST7265, 16-bit RGB parallel |
| Backlight | **GPIO1** | GPIO2 |
| Flash | **4 MB** | 16 MB |
| PSRAM | 8 MB OPI | 8 MB OPI |

## Specs

- MCU: ESP32-S3 (N4R8) — dual-core LX7 @ 240 MHz, 512 KB SRAM, Wi-Fi 802.11 b/g/n, **Bluetooth 5 LE only** (no Classic BT / `BluetoothSerial`)
- Display: 4.3" IPS TFT, 480×272, RGB565, NV3041A over QSPI
- Touch: none / resistive / GT911 capacitive (N / R / C variants) — **the prototype unit is the C (capacitive) variant**; touch not used yet
- microSD slot
- USB-C for power, programming, and serial

## Known-good Arduino setup

- Arduino IDE 2.x, **esp32 by Espressif Systems** 3.x
- Library: **GFX Library for Arduino** (Moon On Our Nation) 1.4.x or newer — install from Library Manager, do not use vendor-bundled copies
- Touch (C variant): `TAMC_GT911`

```cpp
Arduino_DataBus *bus = new Arduino_ESP32QSPI(45 /*CS*/, 47 /*SCK*/, 21, 48, 40, 39);
Arduino_GFX *gfx = new Arduino_NV3041A(bus, GFX_NOT_DEFINED /*RST*/, 0 /*rotation*/, true /*IPS*/);
```

## Gotchas

- Only 0° and 180° rotation work on the NV3041A.
- If the image is noisy, slow the bus: `gfx->begin(32000000)`.
- If colours look inverted, flip the `IPS` argument.
- In Arduino_GFX, SD-card and touch access can break after a display flush — sequence operations carefully.
- With 4 MB flash, app partitions are tight; use a no-OTA / huge-app partition scheme once firmware grows.
