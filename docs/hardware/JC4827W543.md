# Prototype board: Guition JC4827W543R

The prototype display board is a **Guition JC4827W543R** (4.3", 480×272, resistive touch). It was
sold as an "ESP32-4827S043" and shipped with that board's documentation, but the
two boards are **not** compatible — the 4827S043 docs, pin map, and vendor
demos do not apply here.

| | JC4827W543 (this board) | ESP32-4827S043 (seller's docs — ignore) |
|---|---|---|
| Display controller | NV3041A, **QSPI** | ILI6485 / ST7265, 16-bit RGB parallel |
| Backlight | **GPIO1** | GPIO2 |
| Flash | **4 MB** | 16 MB |
| PSRAM | 8 MB OPI | 8 MB OPI |

## Specs

- MCU: ESP32-S3 (N4R8) — dual-core LX7 @ 240 MHz, 512 KB SRAM, Wi-Fi 802.11 b/g/n, **Bluetooth 5 LE only** (no Classic BT / `BluetoothSerial`)
- Display: 4.3" IPS TFT, 480×272, RGB565, NV3041A over QSPI
- Touch: none / resistive XPT2046 / capacitive GT911 (N / R / C variants) — **the prototype unit is the R (resistive) variant**
- microSD slot
- USB-C for power, programming, and serial

### Resistive touch (XPT2046) + microSD — one shared SPI bus

The touch controller and the microSD slot share SCK/MISO/MOSI, each with its
own chip select. Use a dedicated `SPIClass(HSPI)` for this bus, never the
default `SPI` object (see Gotchas).

| Signal | GPIO |
|---|---|
| SCK | 12 |
| MISO | 13 |
| MOSI | 11 |
| Touch CS | 38 |
| Touch IRQ (pen down) | 3 (strapping pin — input only) |
| microSD CS | 10 |

Touch calibration at rotation 0 (raw 12-bit): X 205–3870 (right → left),
Y 400–3725 (bottom → top), pressure threshold 400. Values come from the
[emu8](https://github.com/hexadevti/emu8) project's `board.h` / `touchkeyboard.cpp`;
check yours with the badge's `touchtest` command.

The C variant instead has a GT911 on I2C (SDA 8, SCL 4, INT 3, RST 38). It's
not used by this firmware.

## Known-good Arduino setup

- Arduino IDE 2.x, **esp32 by Espressif Systems** 3.x
- Library: **GFX Library for Arduino** (Moon On Our Nation) 1.4.x or newer — install from Library Manager, do not use vendor-bundled copies
- Touch: no library needed. The badge firmware reads the XPT2046 directly (`dc_touch.cpp`)

```cpp
Arduino_DataBus *bus = new Arduino_ESP32QSPI(45 /*CS*/, 47 /*SCK*/, 21, 48, 40, 39);
Arduino_GFX *gfx = new Arduino_NV3041A(bus, GFX_NOT_DEFINED /*RST*/, 0 /*rotation*/, true /*IPS*/);
```

## Gotchas

- Only 0° and 180° rotation work on the NV3041A.
- If the image is noisy, slow the bus: `gfx->begin(32000000)`.
- If colours look inverted, flip the `IPS` argument.
- Touch/SD break after a display flush if they use the default `SPI` object. Give them their own `SPIClass(HSPI)` ([Arduino_GFX discussion #557](https://github.com/moononournation/Arduino_GFX/discussions/557)).
- Resistive touch needs a firm press; finger taps near the edges are less accurate than in the middle.
- Pull touch CS (38) and SD CS (10) high before using the shared bus, or the SD card may fail to mount from a cold boot.
- With 4 MB flash, app partitions are tight; use a no-OTA / huge-app partition scheme once firmware grows.
